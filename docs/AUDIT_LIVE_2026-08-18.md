# J.A.R.V.I.S. — живой аудит (2026-08-18)

Проверка «как есть»: реальный запуск бэкенда (Orchestrator + локальная Qwen3 GGUF,
офлайн), прогон 6 голосовых команд с замером latency, статический аудит фронтенда.

## 1. Что запускается и работает
- **Бэкенд** поднимается: `python -m core.ws_server` (WS :8771) или REPL `python main.py`.
  Реестр из 20+ инструментов регистрируется, локальные модели грузятся
  (Qwen3-4B analyst-fallback, Qwen3-1.7B fast, Piper-голоса на диске).
- **Фронтенд** (Tauri+React): `npx tsc --noEmit` → **0 ошибок**;
  `npm run test:frontend` (wsProtocol/wsBackend/operatorModel) → **все зелёные**.
- **Fast-path запуска приложений** работает и быстрый: «Открой блокнот» → 0.59s.
- Инфраструктура зрелая: risk-gate/подтверждения, prompt-injection wrap, verifier,
  repair loop, деградация при недоступности облака (см. `scripts/test_core_scenarios.py`).

## 3. Критические дыры (подтверждены кодом + прогоном)

### 3.1 Нет инструментов media и time — а роутер их обещает
`core/router/intent_router.py` содержит категории `INTENT_MEDIA` и `INTENT_SYSTEM`
(музыка, «который час» и т.п.), но в `DEFAULT_REGISTRY` **нет** ни одного
media/музыкального и ни одного time/clock инструмента. Зарегистрированы только:
open_app, close_app, volume, system_status, web_search, web_fetch, list_files,
read_file, write_file, search_files, file_copy, file_move, list_files_recursive,
add_reminder, list_reminders, cancel_reminder, weather, screen_capture,
browser_automation, browser_bridge, computer_use(mouse/keyboard/screenshot).
- Последствие «Поставь музыку» → модель импровизирует и берёт `add_reminder`
  («через 10 мин — Listen to music»). Классический ложный успех.
- Последствие «Который час» → нет tool → «Время не определено» (хотя это тривиальный
  локальный `datetime`).
→ **Codex забыл** реализовать действия под уже заявленные интенты.

### 3.2 Контаминация контекста памяти
В ответы на «Привет» и «Что такое энтропия» вставляются нерелевантные личные факты
(«GTA 5», «Менталист») из долговременной памяти/профиля. Retrieval не фильтрует
релевантность к текущему запросу → ответы выглядят «шизофренично».

### 3.3 Latency локального пути неприемлема
16–42s на tier «fast» при бюджете 1.5s. Первый вызов 42s (холодный старт/warmup
не вынесен из первого запроса). Вероятно инференс идёт на CPU (проверить фактический
offload на GPU: `n_gpu_layers=-1`, но BLAS/CUDA может не подхватываться).

### 3.4 web_search не даёт результата
«Найди книгу…» → «Источник временно не ответил». `web_search` ходит на
`html.duckduckgo.com` (без ключа). В текущем окружении (нет сети/DDG блок) —
деградация формально корректна, но пользователь не получает ни книги, ни ссылки,
ни офлайн-фоллбэка.

## 4. Что сделано плохо / шероховатости
- **state.intent не заполняется**: keyword-роутер есть, но в возвращаемом состоянии
  `intent=null` для всех команд — трудно дебажить маршрутизацию.
- **Конфиг противоречив**: `tier_providers.analyst = "local"`, но `model_tiers.analyst
  = "cx/gpt-5.5"` с пустым endpoint и без ключа. Работает лишь потому, что
  `allow_cloud=false`. Мёртвая/запутанная настройка.
- **Огромный «мусор» в репозитории**: `artifacts/` со спринтами, zip, mp4, wav,
  сотни rollback-снапшотов + файлы `NUL`, `_live_screenshot.png`, дубли `gitignore`
  и `.gitignore`. Раздувает репозиторий и историю.
- **Онбординг**: корневой `README.md` = «# jarvis-v1» (28 байт). Нет инструкции
  запуска (venv, settings.json, модели, запуск backend+frontend).

## 5. Рекомендации (по приоритету)
1. **Media + time actions**: добавить `play_music` (Spotify/URI/локальный плеер) и
   `current_time`/`datetime`; либо убрать `INTENT_MEDIA`, чтобы не порождать ложные
   действия. Запретить подмену интента на `add_reminder`.
2. **Latency**: вынести warmup из первого запроса; проверить GPU-offload;
   маленькая модель (0.5–1.7B) реально уложится в бюджет только на GPU/оптимизации.
3. **Relevance-gate для памяти**: фильтровать retrieval по порогу похожести к запросу,
   чтобы не вставлять «GTA 5» в ответ про энтропию.
4. **Заполнять `state.intent`** и логировать выбранный tool — для наблюдаемости.
5. **Почистить конфиг** (analyst: либо честный local, либо валидный провайдер+ключ)
   и **репозиторий** (`artifacts/` в отдельное хранилище, убрать `NUL`, дубли gitignore).
6. **README**: минимальный «Getting Started».
